# Third-party assets

## IBM Plex Sans and Mono

Bundled via `@fontsource`, SIL Open Font License 1.1.

## MapLibre GL JS

Map renderer, BSD 3-Clause. https://github.com/maplibre/maplibre-gl-js

## OpenFreeMap tiles

Vector tiles and the `dark` style from https://openfreemap.org, built on OpenMapTiles
(BSD 3-Clause / CC BY 4.0) and OpenStreetMap data (ODbL). Attribution is shown on the map
as their terms require.

The emblem and favicon are original drawings for this project.
